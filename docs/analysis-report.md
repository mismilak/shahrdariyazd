| موضوع | نتیجه |
|---|---|

## ۲. شرح سامانه به زبان ساده

سامانه‌ای وب‌محور برای اینکه شهرداری بتواند:
- ماشین‌آلات حمل نخاله و حفار را **ثبت و کارت فعالیت ۶ ماهه** صادر کند،
- برای پروژه‌های ساختمانی/عمرانی **مجوز خاکبرداری و حمل** صادر کند (اطلاعات پروژه از سامانه «سرا»)،
- ورود خودروها به **سایت‌های تخلیه** را از طریق راهبند، پلاک‌خوان و RFID ثبت کند و حجم و هزینه را حساب کند،
- **بازرسان** تخلف را در محل با عکس و موقعیت ثبت کنند،
- شهروندان **خاک مرغوب** درخواست دهند،
- پرداخت‌ها (POS، درگاه، کیف پول «یزد من») و **گزارش‌ها و داشبورد مدیریتی** را داشته باشد.

### نقش‌ها (۵ پنل)
کارشناس سازمان پسماند، بازرس، پیمانکار، شهروند، امور مالی (+ مدیر سامانه)

### ابهامات و ایرادات سند (برای سؤال از کارفرما)
1. «کارفرما فقط به درخواست‌های سامانه‌های آماده ترتیب اثر خواهد داد» — آیا محصول باید از قبل وجود داشته باشد؟ (و جمله «کارفرما باید دفتر در یزد داشته باشد» احتمالاً منظور پیمانکار است.)
2. عنوان «خرید، نصب...» است — آیا **سخت‌افزار** (راهبند، پلاک‌خوان، RFID، POS، سرور) جزو تعهد است؟ از متن به‌نظر فقط اتصال است.
3. **API سامانه‌های سرا، راهبند، یزد من، SSO داخلی، درگاه و پیامک** وجود دارد؟ مستند دارد؟ محیط تست دارد؟
4. حجم خاک از روی راهبند چطور محاسبه می‌شود؟ (ظرفیت خودرو × تعداد تردد؟ یا باسکول؟)
5. داده فعلی برای Migration چیست و چه حجمی دارد؟
6. سرویس نقشه شهرداری چیست (ArcGIS، GeoServer، نشان، ...)؟
7. شماره ماده جریمه در بند ۷-۲۸ خالی است («مطابق ماده ..»).
8. بخش‌های GIS (۱۱ و ۱۲) و Migration (۱۳ و ۱۵) تکراری‌اند.
9. هزینه گواهی افتا و تست نفوذ بر عهده کیست؟
10. تعداد کاربران همزمان، تعداد خودرو و سایت‌های تخلیه (برای سایزینگ).

## ۵. فهرست هزینه‌هایی که باید در قیمت ببینید

### الف) هزینه مستقیم توسعه
- حقوق تیم (۲۹۰ تا ۳۹۰ نفر-روز) + بیمه و سربار پرسنلی
- مدیریت پروژه و جلسات با کارفرما (معمولاً ۱۰ تا ۱۵٪ روی توسعه)

### ب) هزینه‌های قراردادی و مالی
- کارمزد **ضمانت‌نامه بانکی ۱۰٪** + سپرده/وثیقه بانک
- **سپرده ۱۰٪** که ۱۲ ماه بلوکه است (هزینه فرصت)
- **تأمین مالی** کل پروژه تا پرداخت (هیچ پیش‌پرداختی نیست)
- کسورات **بیمه تأمین اجتماعی** (ماده ۳۸) و **مالیات**؛ ارزش افزوده را کارفرما می‌دهد (اگر گواهی ثبت‌نام دارید)
- **بیمه مسئولیت مدنی** و حرفه‌ای
- هزینه‌های تنظیم قرارداد، تمبر، و ...

### ج) هزینه‌های امنیت و مجوز
- **گواهی ارزیابی امنیتی محصول (افتا)** — هزینه آزمایشگاه + زمان (استعلام از آزمایشگاه‌های مورد تأیید افتا)
- گواهی/پروانه فعالیت امن‌سازی و تأیید پرسنل
- **تست نفوذ مجدد** توسط شرکت مورد تأیید افتا (در صورت باقی ماندن ایراد)
- ابزارهای اسکن امنیتی / به‌روزرسانی وابستگی‌ها

### د) هزینه‌های عملیاتی پروژه
- **دفتر در یزد** (اجاره/مشارکت) و ایاب‌وذهاب و اقامت تیم (بند ۷-۴۹)
- سرور توسعه و تست داخلی خودتان (میزبانی عملیاتی با شهرداری است)
- لایسنس‌ها: اگر از نقشه تجاری (مثلاً نشان/پارسی‌مپ) یا ابزار پولی استفاده شود
- سامانه تیکتینگ (می‌تواند متن‌باز باشد، مثل Zammad/osTicket)
- آموزش حضوری کاربران، چاپ مستندات

### هـ) هزینه‌های پس از تحویل
- **۱۲ ماه پشتیبانی رایگان** با SLA سخت (۲۴ ساعت پاسخ، رفع باگ ۶ ساعت تا ۴ روز) — حدود ۱۰ تا ۱۵٪ هزینه توسعه
- تعهد ۱۰ ساله پشتیبانی با سقف ۲۵٪
- رصد مستمر آسیب‌پذیری و وصله‌ها

### و) ذخیره ریسک
- جریمه تأخیر ۰٫۵٪ روزانه، تغییرات ±۲۵٪، تأخیر طرف‌های Integration (سرا، راهبند، یزد من) → **۱۵ تا ۲۵٪ ذخیره**

## ۶. برآورد قیمت (قابل تنظیم با نرخ واقعی شما)

**فرض‌ها:** هزینه تمام‌شده هر نفر-روز (حقوق + بیمه + سربار) در یزد حدود **۴ تا ۶ میلیون تومان**؛ ۳۴۰ نفر-روز (میانه).

| ردیف | قلم | محاسبه | مبلغ تقریبی (تومان) |
|---|---|---|---|
| 1 | توسعه | ۳۴۰ × ۵ میلیون | ۱٬۷۰۰٬۰۰۰٬۰۰۰ |
| 2 | مدیریت پروژه و سفر/دفتر یزد | ~۱۰٪ | ۱۷۰٬۰۰۰٬۰۰۰ |
| 3 | امنیت، افتا، تست نفوذ | تخمینی (استعلام شود) | ۱۵۰ تا ۳۰۰ میلیون |
| 4 | پشتیبانی رایگان ۱۲ ماهه | ~۱۲٪ توسعه | ۲۰۰٬۰۰۰٬۰۰۰ |
| 5 | هزینه مالی (ضمانت، سپرده، تأمین مالی) | ~۸٪ | ۱۸۰٬۰۰۰٬۰۰۰ |
| 6 | ذخیره ریسک | ~۱۵٪ | ۳۵۰٬۰۰۰٬۰۰۰ |
| | **جمع هزینه** | | **≈ ۲٫۷۵ تا ۲٫۹ میلیارد** |
| 7 | سود | ۱۵ تا ۲۰٪ | |
| | **قیمت پیشنهادی** | | **≈ ۳٫۲ تا ۳٫۵ میلیارد تومان** |

- اگر **محصول آماده/نیمه‌آماده** دارید (و فقط سفارشی‌سازی لازم است): ۱٫۵ تا ۲٫۵ میلیارد تومان رقابتی‌تر است.
- **قیمت کف** (زیر آن ضرر می‌کنید): مجموع ردیف‌های ۱ تا ۵ ≈ **۲٫۴ میلیارد تومان** (با فرض‌های بالا).
- پشتیبانی سال دوم به بعد: حداکثر ۲۵٪ مبلغ قرارداد (≈ ۸۰۰ تا ۹۰۰ میلیون تومان در سال).

> ⚠️ این اعداد به نرخ دستمزد واقعی تیم شما حساس است. کافی است نرخ نفر-روز خودتان را جایگزین کنید؛ بقیه به‌صورت درصدی تغییر می‌کند. هزینه گواهی افتا حتماً از آزمایشگاه استعلام شود.

## ۷. دمو برای ارائه

### هدف دمو
نشان دادن اینکه **فرآیند اصلی را فهمیده‌اید** و توان اجرا دارید. کارفرما گفته «سامانه آماده» می‌خواهد، پس دمو باید شبیه محصول واقعی باشد، نه اسلاید.

### سناریوی پیشنهادی ارائه (۱۵ دقیقه)
1. ورود (دکمه «ورود با یزد من» و SSO — شبیه‌سازی‌شده)
2. داشبورد مدیریتی (نمودار درآمد، تعداد مجوز فعال، تخلفات، تردد سایت‌ها)
3. تنظیمات پایه: رسم محدوده منطقه روی نقشه، تعریف تعرفه و تخلف پلکانی
4. ثبت خودرو: کنترل فرمت پلاک ایران، تولید کد ۵ رقمی، پرداخت (شبیه‌سازی) و صدور **کارت فعالیت با QR**
5. مجوز: دریافت اطلاعات پروژه از «سرا» (Mock) با شماره پروانه، رسم مسیر روی نقشه، تخصیص خودرو، صدور کد رهگیری
6. سایت تخلیه: شبیه‌ساز رخداد راهبند/پلاک‌خوان → محاسبه حجم و کسر از شارژ اعتباری به‌صورت زنده
7. پنل بازرس روی موبایل: اسکن QR، ثبت تخلف با عکس و موقعیت → نمایش روی نقشه
8. خاتمه مجوز و صدور گواهی عدم خلاف
9. گزارش و خروجی Excel

### دو سطح دمو

| | دموی A: نمونه کلیکی (Prototype) | دموی B: دموی عملیاتی فرآیند اصلی |
|---|---|---|
| محتوا | فرانت‌اند کامل با داده نمونه، بدون بک‌اند واقعی | فرانت + بک‌اند واقعی + دیتابیس + Mock سرویس‌های بیرونی |
| کاربرد | ارائه اول و جلب نظر | اثبات «سامانه آماده» و پایه پروژه اصلی |
| تیم | ۱ نفر فرانت‌اند | ۱ بک‌اند + ۱ فرانت‌اند |
| زمان | **۸ تا ۱۲ روز کاری** | **۳ تا ۵ هفته** |
| هزینه تقریبی | ۴۰ تا ۷۰ میلیون تومان | ۱۵۰ تا ۲۵۰ میلیون تومان |
| قابلیت استفاده مجدد | فقط UI | ۲۵ تا ۳۵٪ پروژه اصلی |

**پیشنهاد:** دموی A را سریع بسازید، ولی طوری که بعداً به بک‌اند وصل شود (یعنی همان کد فرانت‌اند پروژه اصلی). اگر برنده شدید، دموی B عملاً فاز اول پروژه است.

### پشته فنی پیشنهادی (منطبق با الزامات قرارداد)
- **فرانت‌اند:** React + TypeScript (یا Vue)، کتابخانه UI راست‌به‌چپ، تقویم شمسی، **Leaflet/OpenLayers** برای نقشه، Recharts برای نمودار، PWA برای پنل بازرس
- **بک‌اند:** یکی از Go / .NET Core / Java (بر اساس تخصص تیم)؛ API مستند با OpenAPI
- **دیتابیس:** PostgreSQL + **PostGIS** (برای WKT/GeoJSON)، Redis، MinIO برای فایل‌ها
- **زیرساخت:** Docker Compose (آمادگی K8s)، Nginx (Reverse Proxy + TLS)، Keycloak برای SSO/RBAC، Prometheus/Grafana و لاگ متمرکز
- **Mock:** سرویس‌های ساختگی سرا، راهبند، درگاه، پیامک برای دمو

## ۸. پیشنهادهای مذاکره قبل از ارائه قیمت

1. **زمان‌بندی:** ۱ ماه → حداقل **۴ ماه** (یا فازبندی: فاز ۱ خودرو/کارت/مجوز در ۲ ماه، فاز ۲ اتصالات و GIS پیشرفته).
2. **پرداخت مرحله‌ای:** پیش‌پرداخت ۲۰ تا ۲۵٪ در برابر ضمانت‌نامه + پرداخت بر اساس تحویل هر فاز.
3. **سقف مسئولیت** خسارات امنیتی (مثلاً معادل مبلغ قرارداد).
4. **مسئولیت تأخیر طرف‌های سوم:** تأخیر در تحویل API سرا/راهبند/یزد من نباید مشمول جریمه شود (ماده ۱۵-۶ به این کمک می‌کند؛ صریح‌ترش کنید).
5. **گواهی افتا:** زمان و هزینه آن خارج از ۱ ماه قرارداد دیده شود.
6. **حقوق مالکیت:** حق فروش محصول به سایر شهرداری‌ها (با ذکر در قرارداد) — این ارزش اصلی محصول برای شماست.
7. **سخت‌افزار** صریحاً خارج از تعهد اعلام شود.

## ۹. جمع‌بندی

- پروژه از نظر فنی **قابل انجام** و از نظر کسب‌وکار **منطقی و ارزشمند** است (قابلیت فروش به شهرداری‌های دیگر).
- با شرایط فعلی قرارداد (۱ ماه، بدون پیش‌پرداخت، جریمه سنگین، ۱۰ سال تعهد) **ریسک مالی بالایی** دارد مگر محصول آماده داشته باشید.
- مسیر پیشنهادی: **دموی کلیکی در ۲ هفته** → ارائه → مذاکره روی زمان و پرداخت → قیمت در محدوده **۳ تا ۳٫۵ میلیارد تومان** (ساخت از صفر) یا **۱٫۵ تا ۲٫۵ میلیارد** (با محصول آماده).
